# 双角色前端壳

## 能力

在保留原 `web/` 的前提下，新增 Vue 3 应用，由 aiohttp 在 `/app/` 提供。未登录访问需登录的前端路由时进入登录页。登录后按 `role` 进入管理员壳或用户壳，左侧导航。

仓库根目录 `README.md` 须与上述入口一致：默认 WebRTC 打开 `/` 进入 `/app/`；本机启动写 `./start.sh`（8010）与 `./start-omni.sh`（8091）；Omni 默认 CustomVoice，声音克隆写 `OMNI_MODEL=Qwen/Qwen3-TTS-12Hz-0.6B-Base` 与 `omni_tts_task_type`。原站控制台写 `/index.html`，不是唯一入口。不改 `README-EN.md`。用户工作台说明含连麦后可用麦克风说话。

## 入口

- `/`：默认 WebRTC 启动时重定向到 `/app/`。未登录进入登录页；已登录按角色进入管理员壳或用户壳。
- `/app/`：Vue 3 双角色工作台。开发时 Vite 可将 `/api` 代理到 8010。
- `/index.html`：原 `web/index.html` 控制台，可匿名使用。
- rtmp 启动时 `/` 仍指向 `rtmpapi.html`；rtcpush 启动时 `/` 仍指向 `rtcpushapi.html`。

原 `web/` 下的 HTML/JS/CSS 不被本 change 改写，但生成任务 API 须管理员登录。

## 登录页

- 用户名、密码、提交。失败显示统一错误文案。
- 成功后：`admin` → 管理员首页路由；`user` → 用户首页路由。
- 视觉：Broadcast Gallery。近黑墙为页底，表单放在居中的一块监视器框里（tally + bezel），不是浅色玻璃卡。

## 管理员壳导航

固定五项，顺序：

1. 首页：运营待办以预监墙三面监视器展示（待处理订单、活跃连麦、生成中），以及进入演示连麦的入口。不在此页建立 WebRTC。
2. 演示连麦：选形象、开始/断开、远端画面、发文字 echo/chat、打断、麦克风 ASR、音频上传、录制、动作编排。麦克风识别走本机 `/api/asr`，停止后按当前 echo/chat 自动发送。
3. Avatar 生成：从已接单订单启动生成，并列出已落盘的生成任务。
4. 管理后台：用户列表、创建用户、为用户勾选绑定形象、订单表。管理员可禁用活跃普通用户、启用已禁用普通用户（均经确认）；不能禁用或启用当前登录账号或管理员。没有给其他用户改密的入口。
5. TTS 语音管理：经 8010 代理 Omni，可拉音色、合成试听、上传与删除；不要求填写 8091 地址。可保留指向原 `/tts/` 的次要链接。

## 用户壳导航

固定三项，顺序：

1. 首页：有已发布形象则可连麦；无则引导去「我的资产」发布。未连麦时，若有 `preview_url` 则静音循环播放预览（封面作 poster），否则显示静态封面。连接后可发文字，也可用麦克风说话（本机 `/api/asr`，停止后按 echo 自动发送）。工作放在一块监视器框里（画面、连接、文字发送、麦克风），不是三面墙，也不是浅色玻璃卡。
2. 我的资产：监视器框网格，仅订阅形象。有 `preview_url` 时卡片静音循环播放预览，封面作 poster；仅有封面时显示静图。可发布、取消发布。已发布卡片有明确标记。无订阅时为空态监视器框，不是浅色 empty 卡。
3. 定制数字人：上传区与订单列表分别放在监视器框内。

顶栏显示用户名、改密与退出。改密需填写当前密码与新密码；改密浮层使用 Gallery 监视器语言（管理员与用户共用同一组件）。退出后回到登录页，且不能再拉到 `/api/v1/me`。

用户壳与管理员壳使用同一套 Broadcast Gallery 材料：近黑墙、细侧栏、监视器框。

## 视觉

`/app/` 的登录页、管理员壳与用户壳均使用 Broadcast Gallery：近黑墙（`#111318`）、细侧栏、Electric Indigo（`#4361ee` / `#3f37c9`）作唯一品牌强调，绿/红仅作 tally。玻璃是监视器 bezel 上的涂层，不是浅色 SaaS 卡片。

- 登录页：暗墙上居中一块监视器框。
- 管理员首页：三面监视器墙，大数字，tally 灯。
- 演示连麦、Avatar 生成、管理后台、TTS：同一套材料。工作放在带 tally 与厚 bezel 的监视器框里；演示连麦保持两栏任务布局，不改成三面墙。
- 用户首页：一块监视器承接连麦任务。
- 我的资产、定制数字人：监视器框网格或任务框，表单与表格留在框内。
- 侧栏在桌面可见；窄屏可收起，不作为独立验收项。
