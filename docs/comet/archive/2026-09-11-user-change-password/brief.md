# 目标

已登录的管理员和普通用户都能改自己的密码。管理员仍只负责开户，不能代别人改密。

# 范围

- 登录后提交当前密码与新密码即可改密
- 管理员壳与用户壳顶栏在「退出」旁提供改密入口
- 新密码规则与开户相同：至少 6 个字符
- 改密后当前会话继续有效；该账号其它会话失效
- 未登录改密返回 401

# 非目标

- 不开放自助注册、邮箱验证码、忘记密码
- 管理员不能重置其他用户密码
- 不把管理员首页迁入 WebRTC，不改口型，不归档 `omni-local-tts`
- 不改原 `web/`

# 验收示例

- A1：已登录用户用正确当前密码改密后，旧密码不能再登录，新密码可以；当前 Cookie 仍能访问 `/api/v1/auth/me`
- A2：当前密码错误时改密失败且密码不变；新密码少于 6 位被拒绝
- A3：未登录调用改密接口返回 401
- A4：管理员与普通用户顶栏都能改自己的密码；管理员后台仍只有开户，没有给别人改密的入口
- A5：改密后该账号其它会话失效；原 `web/` 不变

# 约束与不变量

- 工作区：`.worktrees/user-change-password`，基于已合入封面预览的 main
- `omni-local-tts` 仍占用 main 的 current 隔离
- 密码仍用现有 PBKDF2 哈希
- 单测不依赖浏览器

# 决策

- 隔离：独立 worktree
- 管理员和普通用户都能改自己的密码
- 必须提供当前密码
- 管理员不能代改
- 当前会话保留，其它会话作废

# 验证预期

- 顶栏入口用源码断言；浏览器手测留给合入后
