# 双角色前端壳

## 能力

在保留原 `web/` 的前提下，新增 Vue 3 应用，由 aiohttp 在 `/app/` 提供。未登录访问需登录的前端路由时进入登录页。登录后按 `role` 进入管理员壳或用户壳，左侧导航，配色沿用 LiveTalking：主色 `#4361ee` / `#3f37c9`，背景蓝紫渐变，玻璃卡片。

## 入口

- `/`：原 `web/index.html`，行为不变。
- `/app/`：新应用。开发时 Vite 可将 `/api` 代理到 8010。

原 `web/` 下的 HTML/JS/CSS 不被本 change 改写。

## 登录页

- 用户名、密码、提交。失败显示统一错误文案。
- 成功后：`admin` → 管理员首页路由；`user` → 用户首页路由。

## 管理员壳导航

固定四项，顺序：

1. 首页：一期展示说明「演示连麦仍使用原 `/`」的入口链接，以及当前登录管理员名。不在此重建 WebRTC 控制台。
2. Avatar 生成：占位，说明后续版本在此生成形象。
3. 管理后台：用户列表、创建用户、为用户勾选绑定形象。
4. TTS 语音管理：占位，说明后续版本在此管理语音。

## 用户壳导航

固定三项，顺序：

1. 首页：有已发布形象则展示名称与封面/预览；无则引导去「我的资产」发布。不出现 Avatar ID 输入框，不连接 WebRTC。
2. 我的资产：卡片列表，仅订阅形象。可预览、发布、取消发布。已发布卡片有明确标记。
3. 定制数字人：占位，说明后续版本在此提交定制订单。

顶栏显示用户名与退出。退出后回到登录页，且不能再拉到 `/api/v1/me`。

## 视觉

沿用现有演示站 token，不引入另一套品牌色。侧栏在桌面可见；窄屏可收起，不作为本 change 的独立验收项。
