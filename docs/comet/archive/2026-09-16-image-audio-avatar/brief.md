# 目标

管理员对已接单的「图片+音频」订单点生成后，也能产出可入库、可订阅、可连麦的数字人形象。静图循环进现有抽帧管线；直播仍用 TTS 驱动口型。订单里的音频本轮不参与生成。

# 范围

- 已接单的 `image_audio` 订单：把照片展开为短无声视频，再走现有 wav2lip/MuseTalk `genavatar`
- 视频订单、下单表单（仍要图+音频）不变
- 管理端 Avatar 生成页去掉「图+音频无法生成」
- 更新 `custom-order`（及壳层 Avatar 生成一句）；旧 `test_a5` 改为图+音频可生成

# 非目标

- 不改 `web/`，不部署 1.7B，不做支付/自助注册
- 不把订单音频做成 Omni 克隆或预渲染说话视频
- 不新训口型模型、不引入图生视频大模型
- 不改用户首页连麦/ASR

# 验收示例

- A1：已接单的图+音频订单点生成后，成功路径交付形象并订阅该用户，且不自动发布
- A2：视频订单生成行为不变
- A3：未接单或缺少图片时生成失败；图+音频不再因「没有视频」被拒绝
- A4：Avatar 生成页不再写无法生成图+音频；`web/` 无改动

# 约束与不变量

- 工作区：main 当前目录（`isolation: current`）
- 真实 GPU 上无人脸时沿用现有任务失败 → 订单驳回；单测走假任务
- 下单仍要求同时上传图片和音频（音频本轮只存档）

# 决策

- 切片：图+音频订单可生成可连麦形象
- 隔离：当前目录 main
- 方式：静图循环进现有抽帧；直播仍 TTS；音频本轮不参与生成
- 不恢复幽灵 change `omni-local-tts`

# 待解决问题

- 无。用户已确认目标、范围、验收 A1–A4 与非目标。
