# 双角色前端壳

## 能力

在保留原 `web/` 的前提下，新增 Vue 3 应用，由 aiohttp 在 `/app/` 提供。未登录访问需登录的前端路由时进入登录页。登录后按 `role` 进入管理员壳或用户壳，左侧导航。

## 入口

- `/`：原 `web/index.html`，行为不变。
- `/app/`：新应用。开发时 Vite 可将 `/api` 代理到 8010。

原 `web/` 下的 HTML/JS/CSS 不被本 change 改写，但生成任务 API 须管理员登录。

## 登录页

- 用户名、密码、提交。失败显示统一错误文案。
- 成功后：`admin` → 管理员首页路由；`user` → 用户首页路由。
- 视觉：仍为浅色玻璃卡片（本规格不把登录页纳入 Broadcast Gallery）。

## 管理员壳导航

固定五项，顺序：

1. 首页：运营待办以预监墙三面监视器展示（待处理订单、活跃连麦、生成中），以及进入演示连麦的入口。不在此页建立 WebRTC。
2. 演示连麦：选形象、开始/断开、远端画面、发文字 echo/chat、打断、音频上传、录制、动作编排，以及打开原 `/` 的麦克风 ASR 入口。
3. Avatar 生成：从已接单订单启动生成，并列出已落盘的生成任务。
4. 管理后台：用户列表、创建用户、为用户勾选绑定形象、订单表。没有给其他用户改密的入口。
5. TTS 语音管理：经 8010 代理 Omni，可拉音色、合成试听、上传与删除；不要求填写 8091 地址。可保留指向原 `/tts/` 的次要链接。

## 用户壳导航

固定三项，顺序：

1. 首页：有已发布形象则可连麦；无则引导去「我的资产」发布。未连麦时，若有 `preview_url` 则静音循环播放预览（封面作 poster），否则显示静态封面。
2. 我的资产：卡片列表，仅订阅形象。有 `preview_url` 时卡片静音循环播放预览，封面作 poster；仅有封面时显示静图。可发布、取消发布。已发布卡片有明确标记。
3. 定制数字人：上传区、说明、提交、订单列表。

顶栏显示用户名、改密与退出。改密需填写当前密码与新密码。退出后回到登录页，且不能再拉到 `/api/v1/me`。

用户壳视觉仍为浅色玻璃卡片与蓝紫渐变背景，不纳入 Broadcast Gallery。

## 视觉

管理员壳使用 Broadcast Gallery：近黑墙（`#111318`）、细侧栏、Electric Indigo（`#4361ee` / `#3f37c9`）作唯一品牌强调，绿/红仅作 tally。玻璃是监视器 bezel 上的涂层，不是浅色 SaaS 卡片。

- 管理员首页：三面监视器墙，大数字，tally 灯。
- 演示连麦、Avatar 生成、管理后台、TTS：同一套材料。工作放在带 tally 与厚 bezel 的监视器框里；演示连麦保持两栏任务布局，不改成三面墙。
- 侧栏在桌面可见；窄屏可收起，不作为独立验收项。
