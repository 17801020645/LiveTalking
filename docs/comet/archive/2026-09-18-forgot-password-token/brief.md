# 目标

没有邮箱时，用户仍能凭管理员发的一次性令牌在登录页重设密码。令牌错、过期或用户名不存在时，文案不暴露账号是否存在。

# 范围

- 管理员：给普通用户生成一次性令牌（只展示一次，哈希入库，24 小时有效）
- 登录页：用户名 + 令牌 + 新密码 → 改密成功后令牌作废、该用户全部登录会话清除；不自动登录
- 用户名不存在、令牌错、过期、重复使用：统一失败文案
- 不能给管理员或当前登录账号发令牌
- 更新 `auth-rbac`、`web-app-shell`；README 管理员说明带上重置令牌

# 非目标

- 不接邮箱、验证码、自助注册
- 不替代管理员直接改密（代人改密仍可用）
- 不改 `web/` HTML/JS/CSS
- 不改连麦信令

# 验收示例

- A1：有效令牌可为普通用户设新密码；旧密码失效，该用户原有登录会话失效；成功后须用新密码重新登录
- A2：错令牌、过期、重复使用、未知用户名均失败，文案不暴露该用户名是否存在
- A3：登录页有忘记密码入口；管理员普通用户行有发令牌；不能给管理员或自己发
- A4：原 `web/` 无改动；顶栏自己改密与管理员直接改密行为不变

# 约束与不变量

- 工作区：main 当前目录（`isolation: current`）
- 新密码至少 6 个字符（与开户、代人改密相同）
- 明文令牌只在生成接口响应一次，库中只存哈希
- 已禁用用户可用令牌改密，但仍须启用后才能登录
- `POST /api/v1/auth/forgot-password` 公开，无需登录

# 决策

- 切片：一次性令牌，不接邮箱
- 隔离：当前目录 main
- 有效期 24 小时；新令牌作废该用户未使用的旧令牌
- 成功后停在登录页，不自动登录
- 统一失败文案，避免账号枚举
