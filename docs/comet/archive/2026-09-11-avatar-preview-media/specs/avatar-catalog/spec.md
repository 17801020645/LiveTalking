# 形象目录与订阅发布

## 能力

形象文件仍在 `data/avatars/<avatar_id>/`。系统为每个目录维护元数据，并由管理员把形象订阅给普通用户。普通用户只能看见已订阅形象，且最多把其中一个发布到自己的首页。

## 扫描入库

服务启动时扫描 `data/avatars/` 下的一级目录。已存在的 `avatar_id` 更新封面/预览路径与状态；显示名默认等于目录名，已有显示名不强制改写。新目录插入元数据。不删除磁盘上已消失目录对应的行，以免打断订阅，但列表中标记为不可用。

扫描每个目录前，若存在 `full_imgs` 抽帧结果：

- 没有 `cover.jpg` / `cover.jpeg` / `cover.png` / `cover.webp` 时，用第一张抽帧写出 `cover.jpg`
- 没有 `preview.mp4` 时，用抽帧合成约 5 秒无声 `preview.mp4`（帧不足则用全部帧）
- 已有上述规范文件则不覆盖

元数据 `cover_path` / `preview_path` 指向磁盘上解析到的封面与预览。封面仍可回退到 `full_imgs` 或目录内第一张图；预览只认规范文件名 `preview.mp4`。

## 生成后补写

管理员生成任务（订单生成或 `POST /api/avatar/task`）在状态变为 `completed` 后，对该 `avatar_id` 执行与扫描相同的补写，并刷新元数据。生成 `failed` 时不写出封面或预览。测试假任务成功路径同样写出这两份文件。

## 订阅

- 管理员将某 `avatar_id` 绑定到某普通用户，或解除绑定。
- 解除绑定时，若该条是已发布订阅，则该用户不再有已发布形象。
- 同一用户对同一形象不重复绑定。
- 普通用户查询自己的订阅列表；不能通过猜测 `avatar_id` 读取未订阅形象的元数据（返回 404，与不存在相同）。

## 发布

- 用户将其一条订阅标为已发布。该用户其它订阅的已发布标记被清除。
- 用户可取消发布，首页进入未发布空态。
- `GET /api/v1/me/home` 返回当前用户已发布形象的元数据（名称、封面、预览 URL）；没有则 `published: null`。

## 媒体访问

- `GET /api/v1/media/avatars/{avatar_id}/cover`
- `GET /api/v1/media/avatars/{avatar_id}/preview`

须登录，且仅管理员或已订阅该形象的用户可访问；否则 401 或 404。

## 管理员可见性

管理员可列出全部形象元数据，供绑定使用。上传视频生成新形象仍走现有 Avatar 生成接口。
