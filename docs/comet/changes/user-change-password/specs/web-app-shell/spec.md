# 双角色前端壳

## 能力

在保留原 `web/` 的前提下，新增 Vue 3 应用，由 aiohttp 在 `/app/` 提供。未登录访问需登录的前端路由时进入登录页。登录后按 `role` 进入管理员壳或用户壳，左侧导航，配色沿用 LiveTalking：主色 `#4361ee` / `#3f37c9`，背景蓝紫渐变，玻璃卡片。

## 入口

- `/`：原 `web/index.html`，行为不变。
- `/app/`：新应用。开发时 Vite 可将 `/api` 代理到 8010。

原 `web/` 下的 HTML/JS/CSS 不被本 change 改写，但生成任务 API 须管理员登录。

## 登录页

- 用户名、密码、提交。失败显示统一错误文案。
- 成功后：`admin` → 管理员首页路由；`user` → 用户首页路由。

## 管理员壳导航

固定四项，顺序：

1. 首页：待办卡片（待处理订单、活跃会话、进行中生成任务）以及打开原 `/` 的演示连麦入口。不在此重建 WebRTC 控制台。
2. Avatar 生成：从已接单订单启动生成，并列出已落盘的生成任务。
3. 管理后台：用户列表、创建用户、为用户勾选绑定形象、订单表。没有给其他用户改密的入口。
4. TTS 语音管理：经 8010 代理 Omni，可拉音色、合成试听、上传与删除；不要求填写 8091 地址。可保留指向原 `/tts/` 的次要链接。

## 用户壳导航

固定三项，顺序：

1. 首页：有已发布形象则可连麦；无则引导去「我的资产」发布。未连麦时，若有 `preview_url` 则静音循环播放预览（封面作 poster），否则显示静态封面。
2. 我的资产：卡片列表，仅订阅形象。有 `preview_url` 时卡片静音循环播放预览，封面作 poster；仅有封面时显示静图。可发布、取消发布。已发布卡片有明确标记。
3. 定制数字人：上传区、说明、提交、订单列表。

顶栏显示用户名、改密与退出。改密需填写当前密码与新密码。退出后回到登录页，且不能再拉到 `/api/v1/me`。

## 视觉

沿用现有演示站 token，不引入另一套品牌色。侧栏在桌面可见；窄屏可收起，不作为本 change 的独立验收项。
